## 🚀 Quick Start

### Prerequisites

- ☕ JDK 21
- 🔧 Git
- 💻 A Java-compatible IDE or code editor

### 1. Clone the repository

```bash
git clone https://github.com/Tejaskalmegh1/java-labs.git
cd java-labs
```

### 2. Verify Java

```bash
java -version
javac -version
```

### 3. Compile and run

```bash
javac 01-basics/HelloWorld.java
java -cp 01-basics HelloWorld
```

### 📝 Commit Convention

```text
feat:      Add new implementations
fix:       Correct bugs
docs:      Update documentation
test:      Add automated tests
refactor:  Improve code structure
build:     Update build configuration
```

Example:

```bash
git add .
git commit -m "feat: add Java fundamentals examples"
git push origin main
```
